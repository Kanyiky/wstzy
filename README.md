# 五术搬财资源库 · Resource Archive

极简风格的资源分享网页，适配手机与电脑。

## 功能

- 实时搜索标题 / 描述
- 分类筛选（横向滚动标签）
- 响应式卡片网格
- 毛玻璃顶栏 + 流畅动画
- 纯静态，可直接部署到 GitHub Pages

## 使用方式

1. 将本仓库推送到 GitHub
2. 仓库 Settings → Pages → Source 选择 `main` 分支根目录
3. 访问 `https://你的用户名.github.io/仓库名`

## 本地预览

直接用浏览器打开 `index.html` 即可。
