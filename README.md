## 这是什么

本站把传统五术与现代实用技能放在一起：  
一边理解方法与格局，一边掌握可落地的本事与副业路径。

适合：
- 想系统了解五术相关资料的爱好者  
- 想学技能、做副业、提升收入的普通人  
- 需要可检索、可分类资源入口的人  

---

## 资源分类

| 分类 | 说明 |
|------|------|
| **山** | 风水、阵法、传统术法等相关资料 |
| **医** | 中医、养生、实用医理与案例 |
| **命** | 命理、八字、运势相关内容 |
| **相** | 面相、手相、风水形法等 |
| **卜** | 占卜、预测、决策参考类资料 |
| **技能教程** | 可直接上手的实操课程与方法 |
| **创业副业** | 搞钱项目、副业思路与落地经验 |
| **奇异杂集** | 冷门、稀缺、有趣的杂项合集 |
| **学习资料** | 系统学习与拓展阅读材料 |

---

## 使用方式

1. 点击上方按钮进入资源库页面  
2. 按分类筛选或搜索关键词  
3. 点击资源卡片查看简介并下载  
4. 需要其他资源，可联系客服协助查找  

> 资源仅供学习参考，请勿用于商业倒卖。

## 关于「搬财」

「搬财」强调的是：  
**先提升认知与技能，再把能力变成可持续收入。**

持续整理与更新，欢迎关注公众号 **五术推** 获取更多内容。
